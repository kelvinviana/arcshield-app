# ArcShield • ABNT NBR 17227:2025 / IEEE 1584

Aplicação web interativa para cálculo de energia incidente de arco elétrico, determinação de fronteira de arco, especificação de vestimentas/EPIs de proteção térmica e emissão de etiquetas de advertência conforme as normas **ABNT NBR 17227:2025**, **IEEE 1584-2018** e **NR-10**.
